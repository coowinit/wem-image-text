# WEM Image Text v1.0.0 回归测试清单

此清单用于发布前后回归。已在目标 WordPress 站点验证的项目可由维护者勾选记录；不同主题、浏览器或辅助技术环境仍需按实际情况测试。

## 区块注册与内容编辑

- [ ] 插件启用后无 PHP 致命错误。
- [ ] 区块插入器可搜索到 WEM Image Text。
- [ ] 新建区块后出现图片区与内容区。
- [ ] 图片区可正常选择、替换图片并设置替代文本。
- [ ] 内容区可编辑 Heading、Paragraph，并可插入 List、Buttons 等允许的原生区块。
- [ ] 保存、刷新、重新打开后内容和设置保持一致。

## 手机端

- [ ] 图片优先。
- [ ] 文字优先。
- [ ] 手机端 Text Margin 在 0–48px 范围内有效。
- [ ] 手机端布局不受桌面 Gap 数值影响。
- [ ] 320px 窄屏无横向溢出。
- [ ] 长标题、长段落、列表和按钮显示正常。
- [ ] 编辑器预览与前台布局一致。

## 主题、插件与无障碍

- [ ] 在目标主题中检查全局图片、标题、段落和按钮样式。
- [ ] WEM Image Text 单独启用时正常。
- [ ] 与 WEM Swiper Gallery 同时启用时正常。
- [ ] 键盘操作、图片替代文本和焦点状态正常。
